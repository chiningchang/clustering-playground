# Clustering Playground

An interactive classroom activity for exploring clustering and unsupervised machine learning by grouping everyday foods.

## Activity

- Arrange 18 food cards into 2–5 groups using drag and drop or dropdown menus.
- Name your groups and explain your rationale.
- Generate and copy a summary to share with your class.
- Discuss how features and human interpretation shape grouping decisions.

No login, installation, or server is required. Work stays in the current browser tab; refreshing clears it.

## GitHub Pages

In repository **Settings → Pages**, select **Deploy from a branch**, **main**, and **/ (root)**, then save.

Website: https://chiningchang.github.io/clustering-playground/

You can also download `index.html` and open it in a browser. If clipboard access is unavailable, select and copy the summary manually.
