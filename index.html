The connection to machine learning

You explored the idea behind clustering.

Clustering means grouping items based on similarities. It is one type of unsupervised machine learning: a system looks for patterns without being given the correct group labels.

This activity is a hands-on analogy, not an AI algorithm. You chose the similarities, formed the groups, and interpreted them. In machine learning, people choose the features (characteristics) and method, an algorithm forms groups, and people interpret the results. A group name is an interpretation—not a label the algorithm was taught beforehand.

  • Did classmates find different groups in the same foods?
  • How would your groups change if you focused on a different characteristic?
  • If AI grouped students by learning behaviors, what would a teacher need to check before acting on those groups?

Remember: A pattern is not automatically meaningful, useful, or fair.

Instructor notes

Introduce the challenge without providing categories. Invite learners to create and name their groups, explain their rationale, and share the summary with the class. Compare the characteristics learners chose, then discuss the connection to unsupervised learning.

There is no answer key. Ask learners to justify a consistent grouping rule. Items such as avocado, tomato, mushroom, yogurt, and sushi can invite different interpretations. Compare groups based on characteristics such as ingredients, preparation, texture, how foods are eaten, or cultural context; avoid treating one familiar food classification as the correct answer. Choosing 2–5 groups is a classroom activity limit; unsupervised learning does not always require that range. This page does not run a model or collect class responses.

What should I notice?

K is the number of groups you ask the algorithm to form. A center is the average position of the points in a group. The algorithm alternates between assigning points and updating centers until assignments stop changing.

Try the same data with a different K or different starting centers. Different starting centers can lead to different results. This example uses Euclidean distance and features on the same scale. Real datasets may need scaling first.

If a group has no points, this demonstration keeps its center in place. People still need to interpret what the groups mean.

How do I read this tree?

Each letter represents an observation. A branch joins two groups. Its height represents their distance when they merged; it does not represent time. Left-to-right spacing is for layout and does not measure similarity.

A horizontal cut selects the branches beneath it as groups. A higher cut generally gives fewer groups. A merge exactly at the cut height is included in this demonstration.

Average linkage: average distance across all point pairs between two groups. Single linkage: the closest pair. Complete linkage: the farthest pair. All three use Euclidean distance between individual points.
